# Paws Unlimited

Professional pet sitting service website for the Cape Town Metro area, operating in partnership with WePetSit South Africa.

## About

Paws Unlimited is a certified, professional pet sitting service based in Durbanville, Cape Town. This website showcases our services, certifications, and makes it easy for pet owners to connect with us via WhatsApp or email.

## Project Structure

This is a single-page static website built with:
- Pure HTML5
- Embedded CSS (no external stylesheets)
- Responsive design with mobile-first approach
- Google Fonts (Nunito)
- Inline JavaScript for mobile navigation

## Features

- **Responsive Navigation**: Fixed header with hamburger menu for mobile devices
- **Hero Section**: Eye-catching landing with key stats and call-to-action
- **Service Cards**: Six different pet care service options with pricing
- **About Sections**: Information about the business and founder (Jason Myburgh)
- **Certifications Display**: Professional qualifications and training
- **Service Area Map**: Embedded Google Maps showing coverage area
- **FAQ Section**: Common questions answered
- **Contact CTAs**: Multiple WhatsApp and email contact points throughout

- GitHub Pages

- Vercel
- Traditional web hosting (cPanel, etc.)

Simply upload `index.html` to your web server root directory.

Open `index.html` directly in your browser - no build process or dependencies required.
